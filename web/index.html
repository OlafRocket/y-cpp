y-cpp live test

Two real Yjs peers running in this page. Edit both sides, sync them, or exchange base64 updates with the ycpp C++ CLI — all three speak the same Yjs v1 binary protocol.
Testing against the C++ implementation 
# build once:  cmake -B build && cmake --build build
./build/ycpp new /tmp/doc.ydoc
./build/ycpp insert /tmp/doc.ydoc 0 "hello from C++"
./build/ycpp export /tmp/doc.ydoc          # copy output → paste into a peer's "Apply update"
./build/ycpp apply  /tmp/doc.ydoc BASE64   # BASE64 = a peer's "Export state" output
./build/ycpp show   /tmp/doc.ydoc          # converged text
Round-trip a doc through both worlds: the text ends up identical on every peer, concurrent edits merge with the same YATA ordering everywhere. The shared text lives in the Yjs root type "default".
